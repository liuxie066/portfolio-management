## Findings

### DR-S1-01-未修复-中-共享Bitable协议契约仍由holdings模块所有，cash-flow和通用adapter反向依赖业务模块

- **入口/函数**: `normalize_cash_flow_event()` and
  `FeishuBitableEventAdapter.start()/subscribe()`
- **文件(行号)**: `src/app/cash_flow_event_service.py:12-24`;
  `src/feishu/bitable_event_adapter.py:10-14, 31-32, 88, 119-120`
- **输入场景**: A future protocol-level limit, file type, event type, or
  subscription event constant changes for the shared Bitable listener, or the
  holdings module is reorganized independently of cash flow.
- **实际分支**: The new cash-flow normalizer aliases all protocol constants and
  receiver limits from `holdings_event_service`; the supposedly shared SDK
  adapter also imports and executes `HOLDINGS_*` constants directly.
- **预期行为**: Shared Feishu protocol facts should have a neutral owner used by
  both table-specific domains. Holdings and cash flow should depend on that
  owner, while the generic adapter should not depend on either business domain.
- **实际行为**: Cash flow and the generic adapter are coupled to holdings module
  naming and lifecycle. Changing or extracting holdings event behavior can
  silently change cash-flow transport behavior or create an import cycle when
  S2/S3 compose both handlers.
- **直接证据**: `CASH_FLOW_EVENT_TYPE = HOLDINGS_EVENT_TYPE`,
  `CASH_FLOW_FILE_TYPE = HOLDINGS_FILE_TYPE`, and the adapter registers and
  subscribes using `HOLDINGS_EVENT_TYPE/HOLDINGS_FILE_TYPE/
  HOLDINGS_SUBSCRIPTION_EVENT_TYPE`. These are protocol facts, not holdings
  decisions.
- **影响**: Semantic ownership drift and avoidable cross-domain coupling in the
  foundation intended to be shared by two independent handlers; S3 integration
  becomes harder to reason about and more vulnerable to circular imports.
- **建议改法和验证点**: Extract the common event/file/subscription constants and
  receiver bounds to a neutral `bitable_event_contract` module. Make holdings
  re-export the old names for compatibility, and have cash flow plus the generic
  adapter import neutral names. Re-run both holdings and cash-flow normalizer/
  adapter suites and add an assertion that their event types remain identical.
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中
