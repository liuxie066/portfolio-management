## Findings

The three findings in the prior review are closed:

- Unattached aggregate `PortfolioValuation` payloads fail every persistence
  attempt. The generic builder and compatibility adapter are nonofficial;
  official in-memory capability is issued only by ValuationService or the
  type-checked CLOSED factory. Normal and CLOSED consumers require their own
  source, so neither authority can be routed through the other entrypoint.
- Explicit normalized input must match the complete digest of the exact object
  attached to its compatibility projection before the compatibility projection
  itself is validated. Nonprojected source, provenance, component, row-source,
  and zero-exclusion substitutions therefore fail before calculation or write.
- `HoldingSnapshot` rejects zero after eight-decimal normalization, including
  positive and negative values that round to zero. Normal, direct repository,
  and compensation construction share the same model invariant.

The re-review also verified that canonical persisted-row serialization and the
v2 digest have one domain owner. Normalized target evidence, row evidence,
SnapshotService local evidence, and compensation completion evidence consume
that same formula; the domain no longer imports the application service to
compute it.
