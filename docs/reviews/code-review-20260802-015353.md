## Findings

### AGG-CR-01 — 未修复 — 高 — EnvironmentFile can disable secure mode and redirect credential lookup in every generated unit

- **入口/函数**: generated service `EnvironmentFile=` +
  `_render_feishu_credential_directives()` ->
  `secure_feishu_credentials_required()` / `read_systemd_credential()`
- **文件(行号)**: `scripts/install_linux.py:329-342, 359-486`;
  `docs/holdings-event-listener-runbook.md:75-86`
- **输入场景**: The preserved PM environment file contains either
  `PM_REQUIRE_SECURE_FEISHU_CREDENTIALS=0` or a stale/custom
  `CREDENTIALS_DIRECTORY=...` assignment. The transient subscription command
  uses the same file.
- **实际分支**: Generated units set secure mode with `Environment=...=1` and
  rely on systemd to export `CREDENTIALS_DIRECTORY`, but also load the shared
  environment file. systemd's documented precedence says `EnvironmentFile=`
  overrides `Environment=` and variables defined by the service manager. The
  file can therefore turn secure mode off, redirect the resolver away from the
  read-only per-unit credential directory, or do both. Unit ordering does not
  repair this precedence.
- **预期行为**: Every credential-bearing execution must set the secure-mode flag
  and the exact system credential directory after the shared env has been
  assembled, so a legacy/operator env line cannot weaken or redirect the
  credential boundary.
- **实际行为**: Plaintext fallback can be re-enabled despite the generated unit
  claiming secure mode, and a custom directory can be treated as the systemd
  credential source.
- **直接证据**: The official `systemd.exec` contract states that settings from
  `EnvironmentFile=` override `Environment=` and that later environment sources
  win. It also documents `/run/credentials/UNITNAME` for system services when
  interpolation is unavailable:
  https://raw.githubusercontent.com/systemd/systemd/main/man/systemd.exec.xml
- **影响**: All scheduled jobs, API, quality producer, receipt dispatcher,
  listener, preflight, and the documented one-shot subscription can violate the
  core “encrypted credential only” invariant. Preflight may report success
  under the same weakened environment and cannot detect the bypass.
- **建议改法和验证点**: Prefix every credential-bearing `ExecStart` with
  `/usr/bin/env PM_REQUIRE_SECURE_FEISHU_CREDENTIALS=1
  CREDENTIALS_DIRECTORY=/run/credentials/<exact-unit-name>` while retaining the
  least-privilege `LoadCredentialEncrypted` grants. Do the same for the bounded
  transient subscription command. Add regressions that inject conflicting
  variables through the shared env contract and assert the final exec prefix
  remains authoritative for all units and both preflight commands.
- **修复风险（低/中/高）**: 中
- **严重程度（低/中/高/严重）**: 高
